TCF7/ID2 analysis of GSE270651
Overview

This directory contains an exploratory reanalysis of the single-cell RNA-sequencing dataset deposited under GEO accession GSE270651, associated with White et al., “Clonal succession after prolonged antiretroviral therapy rejuvenates CD8+ T cell responses against HIV-1” (Nature Immunology, 2024; https://doi.org/10.1038/s41590-024-01931-9).

The workflow examines transcriptional differences among four CD8+ T-cell populations defined by ID2 and TCF7 expression:

    ID2+TCF7+
    ID2+TCF7-
    ID2-TCF7+
    ID2-TCF7-

The analyses include Gaussian mixture model (GMM) classification, violin plots, differential-expression heatmaps and gene-set enrichment analysis (GSEA).

Required input files

The workflow uses the following processed input files:
Datasets.rds

A Qlucore-exported object containing:

    A gene-by-cell normalized expression matrix.
    Gene identifiers and gene symbols.
    Cell-level annotations.

This file is used by 01_GMM_classification.R.


GMM_datasets.rds

Generated by 01_GMM_classification.R. It contains the combined cell annotations and expression values together with the GMM-derived ID2/TCF7 classifications. It is used by the violin-plot and heatmap scripts.
A copy may also be provided in the associated Zenodo record so that the downstream analyses can be reproduced without rerunning the GMM classification.

Datasets_GMM_corrected_ID2TCF7_for_Volcano_and_GSEA.rds

The corrected analysis object used by 05_GSEA_analysis.R. It contains the normalized expression matrix, gene annotations and corrected ID2_TCF7_expression cell classifications in matching cell order. This file is provided through Zenodo. The differential-expression calculations are performed directly in R.


Workflow

Run the scripts in numerical order from the GSE270651 analysis directory. Restarting R before running the complete workflow is recommended.
  
  1. 01_GMM_classification.R

This script:

    Loads Datasets.rds.
    Transposes the normalized expression matrix from genes × cells to cells × genes.
    Uses gene symbols where available and Ensembl identifiers as fallbacks.
    Combines expression values with the cell-level annotations.
    Fits independent two-component Gaussian mixture models to ID2 and TCF7 expression using mclust.
    Defines the ID2 and TCF7 cutoffs at the point where the posterior probabilities of the two mixture components are equal.
    Classifies cells into the four ID2/TCF7 populations.
    Produces an ID2-versus-TCF7 scatter plot showing the two GMM cutoffs.
    Exports cell counts by participant, time point and ID2/TCF7 population.
    Saves the classified dataset as GMM_datasets.rds.

Main outputs include:
GMM_datasets.rds
GMM_cutoff.svg
cell_counts_byPatient_byTP_bySubpop.csv

  
  2. 02_violin_plots.R

This script loads GMM_datasets.rds and visualizes selected gene-expression distributions across the GMM-defined ID2/TCF7 populations. The analyses can be stratified by participant, time point or other available clinical annotations. The script generates the violin plots and associated statistical annotations used to compare the transcriptional states.


  3. 03_heatmap.R

This script loads GMM_datasets.rds and:

    Retains the four predefined ID2/TCF7 populations.
    Identifies numeric gene-expression columns.
    Performs a global Kruskal–Wallis test, or optionally a one-way ANOVA, for every gene across the four populations.
    Corrects P values using the Benjamini–Hochberg procedure.
    Selects the top-ranked genes passing the specified adjusted-P-value threshold.
    Summarizes expression within each population.
    Standardizes each gene across populations for visualization.
    Hierarchically clusters the genes and draws the resulting heatmap.
    Exports the population means, plotted Z-scores and gene-level statistical results.

The heatmap Z-scores are calculated per gene across the four population-level summaries. 

4. 04_GSEA_functions.R

This is a helper script sourced by 05_GSEA_analysis.R; it is not normally run independently. It contains functions to:

    Construct named gene-set lists.
    Convert differential-expression results into ranked gene vectors.
    Run fgsea.
    Calculate pathway-level plotting variables.
    Import and export fgsea result tables while handling the leadingEdge list-column.
    Produce GSEA dot plots.

5. 05_GSEA_analysis.R

This script performs two comparisons:

    ID2+TCF7+ versus ID2-TCF7+
    ID2+TCF7+ versus ID2+TCF7-

For each comparison, the script:

    Loads Datasets_GMM_corrected_ID2TCF7_for_Volcano_and_GSEA.rds.
    Performs gene-wise Mann–Whitney/Wilcoxon rank-sum tests.
    Calculates mean-expression log2 fold changes and Benjamini–Hochberg-adjusted P values.
    Generates a volcano plot.
    Ranks genes by log2 fold change.
    Runs fgsea using the custom GMT collection.
    Retains pathways meeting the configured FDR and absolute-NES thresholds.
    Exports raw and filtered GSEA tables.
    Produces the final directional GSEA dot plots.

Positive log2 fold changes and positive normalized enrichment scores indicate enrichment in ID2+TCF7+ cells. Negative values indicate enrichment in the reference population named in the comparison.

Session information

Each executable analysis script writes the output of sessionInfo() to the session_info/ directory. These files record the R version, operating system and versions of loaded packages used for the analysis. They are included to help identify differences caused by package or software updates.

The session-information files are documentation, not input data, and should be committed to GitHub. 04_GSEA_functions.R does not require a separate session-information file because it is sourced and executed within 05_GSEA_analysis.R; its loaded-package versions are therefore captured in 05_GSEA_sessionInfo.txt.
Reproducibility notes

    Run the scripts from the GSE270651 directory so that relative paths resolve correctly.
    Use the exact custom GMT supplied in data/.
    Small numerical differences may arise when R or package versions change; consult the corresponding session_info file when comparing runs.
    The source data remain attributable to the original study and GEO accession GSE270651.
